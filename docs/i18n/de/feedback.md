# Rückmeldung

Libera Suite ist jung. Am nützlichsten sind die langweiligen, genauen Einzelheiten: was Sie getan haben, was passiert ist, was Sie stattdessen erwartet haben.

## Etwas funktioniert nicht

Bitte geben Sie an:

- **Was Sie getan haben**: den Menüeintrag, die Schaltfläche, die Taste.
- **Was passiert ist**: den genauen Wortlaut einer Meldung, falls es eine gab. Ein Bildschirmfoto ist besser als eine Beschreibung.
- **Das Dokument**, wenn es um ein Dokument geht und Sie es teilen können. Ein Dokument, das das Problem auslöst, ist mehr wert als jede Beschreibung. Wenn Sie es nicht teilen können, sagen Sie es: Ein verkleinertes Dokument, das sich noch genauso verhält, ist ebenso gut.
- **Ihre Plattform**: die Ausgabe von `libera --diagnose`. Sie enthält die Versionen, ob sich überhaupt ein Fenster öffnen lässt und woher die Editoren stammen. Einmal einfügen genügt.

Darstellungsprobleme lassen sich ohne das Dokument kaum verfolgen: Die Layout-Engine tut etwas Bestimmtes mit etwas Bestimmtem im Dokument. Wir brauchen beides.

## Etwas fehlt

Sagen Sie, was Sie erledigen wollten. Die Funktion, die Sie verwendet hätten, hilft uns; ob es eine bessere Antwort gibt, entscheidet aber die Aufgabe dahinter.

Manches fehlt bekanntermaßen und muss nicht gemeldet werden. Siehe [Was heute funktioniert](main/status.md).

## Wohin damit

Schicken Sie es an [github.com/abilian/libera-suite/issues](https://github.com/abilian/libera-suite/issues), wohin auch Help ▸ Suggest a feature aus der Anwendung führt. Schreiben Sie gern auf Englisch oder Französisch.

Dieses Repository ist der öffentliche Spiegel: Es enthält den Quellcode, ohne die internen Notizen. Wenn Sie es lieber nicht verwenden, erreichen Sie uns über [abilian.com](https://abilian.com/).
