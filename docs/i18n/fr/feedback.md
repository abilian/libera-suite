# Vos retours

Libera Suite est jeune. Les informations les plus utiles sont les détails précis, même ennuyeux : vos actions, le résultat obtenu, le résultat attendu.

## Quelque chose ne marche pas

Merci d'indiquer :

- **Vos actions** : l'élément de menu, le bouton, la touche.
- **Le résultat** : le message exact s'il y en a eu un. Une capture d'écran vaut mieux qu'une description.
- **Le document**, si le problème le concerne et que vous pouvez le partager. Un document qui reproduit le problème vaut plus que toute description. Si vous ne pouvez pas le partager, dites-le : un document réduit qui pose toujours problème fait tout aussi bien l'affaire.
- **Votre plateforme** : la sortie de `libera --diagnose`, qui donne les versions, dit si une fenêtre peut s'ouvrir et d'où viennent les éditeurs. Un seul copier-coller suffit.

Les problèmes de rendu, en particulier, sont difficiles à suivre sans le document : le moteur de mise en page fait quelque chose de précis avec quelque chose de précis dans le document. Il nous faut les deux.

## Quelque chose manque

Décrivez la tâche que vous cherchiez à accomplir. La fonction que vous auriez utilisée nous aide, mais la tâche elle-même décide s'il existe une meilleure réponse.

Certains manques sont connus et n'ont pas besoin d'être signalés. Voyez l'[État des lieux](main/status.md).

## Où l'envoyer

Envoyez-le sur [github.com/abilian/libera-suite/issues](https://github.com/abilian/libera-suite/issues), là où mène aussi Help ▸ Suggest a feature depuis l'application. Vous pouvez écrire en français.

Ce dépôt est le miroir public : il contient le code source, sans les notes internes. Si vous préférez ne pas l'utiliser, joignez-nous par [abilian.com](https://abilian.com/).
