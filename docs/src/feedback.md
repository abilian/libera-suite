# Feedback

Libera Suite is early. The most useful thing you can send is the boring specific detail: what you did, what happened, what you expected instead.

## Something is broken

Please include:

- **What you did**: the menu item, the button, the keystroke.
- **What happened**: the exact message if there was one. A screenshot beats a description.
- **The document**, if the problem is about a document and you can share it. A document that reproduces the problem is worth more than any description of it. If you cannot share it, say so: a reduced document that still misbehaves is just as good.
- **Your platform**: `libera --diagnose` output, which has the versions, whether a window can be opened at all, and where the payload came from. One paste covers it.

Rendering problems in particular are hard to chase without the document: the layout engine is doing something specific with something specific in the document. Both are needed.

## Something is missing

Say what you were trying to get done. The feature you would have used helps, but the task behind it decides whether there is a better answer.

Some things are known to be missing and do not need reporting. See [What works today](guide/status.md).

## Where to send it

Send it to [github.com/abilian/libera-suite/issues](https://github.com/abilian/libera-suite/issues), which is also where Help ▸ Suggest a feature goes from inside the application.

That repository is the public mirror: it carries the source and not the internal notes. If you would rather not use it, reach us through [abilian.com](https://abilian.com/).
